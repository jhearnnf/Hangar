Set up Hangar

Two questions, and you can change both later under Settings at the foot of the sidebar.

Hangar lists the folders inside this one as your projects. Pick the folder your code sits in — not a project itself, but the folder holding them all.

When a project has been finished with and sits quiet for a minute, Hangar copies it to the folder below. Optional — leave it off and Hangar never writes anything outside your projects folder.

This folder is made to match your projects exactly, so anything you put in it that is not in your projects folder gets deleted. Point it somewhere that holds nothing else.

Hangar listens on your home network so the Hangar app on your phone can see the same projects and the same terminals. Nothing leaves the house — the phone talks straight to this PC over the router, and there is no account and no cloud anywhere in it.

On the phone, Hangar finds this PC by itself. If it cannot, type one of these in by hand:

Pair a phone

Type the code into the phone once. It lasts five minutes and one use; after that the phone keeps a key of its own and never needs a code again.

Phones that can connect

A paired phone can open terminals on this PC and type into them, which is the same as sitting here. Only pair phones you own, and remove any you no longer use.

Puts Hangar in the ordinary startup list — the one the Startup tab of Task Manager shows. No service, nothing elevated, and unticking this takes it straight back out. Worth having on if you want your phone to be able to reach Hangar without walking over to the PC first.

Hangar comes up with no window at all, just an icon by the clock — so the terminals and the phone connection are there without a window jumping in front of whatever you were doing. Click the icon for the window back. With this on, closing the window hides it instead of quitting, so nothing you had running is lost; Quit from the tray menu ends Hangar properly.
